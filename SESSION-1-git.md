# Faculty Systems Training

September 9, 2026

> `git` is a trust and provenance system, not a backup tool.

## Topics

1. **Git is a workflow discipline**, not a storage or backup discipline. Git/GitHub provide the canonical version of code.
2. **AI as co-author / Assistant**
    - Obscure Commands - [aliases](https://gist.github.com/nmagee/376c9b8d19edde584b31f44d3936d59c)
    - Tagging
    - Releases
    - Merge Conflicts
3. **GHA and Automation**
    - [Example Action using `pytest`](https://github.com/nmagee/gha-demo)
    - [Example Action to Test/Build/Deploy](https://github.com/UVADS/building-api)
4. **GHA and Agents** - human in-the-loop (or not!)
    - Open PRs on a Schedule
    - Respond to Issues
    - Upgrade & Debug
5. **MCPs**
    - [AWS](https://aws.amazon.com/products/developer-tools/agent-toolkit-for-aws/)
    - [GitHub](https://github.com/github/github-mcp-server)
    - [Rivanna](https://github.com/uvads/rivanna-mcp)
